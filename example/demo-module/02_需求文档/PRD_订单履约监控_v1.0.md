# PRD · 订单履约监控模块

## 文档信息

| 项 | 值 |
|---|---|
| 模块 | 订单履约监控 |
| 版本 | v1.0 |
| 最后更新 | 2026-10-15 |
| 状态 | 示例（demo） |

## 一、背景与目标

订单在承诺时效内未发出时，运营无法及时发现，直到客户催单才被动响应。
本模块把"距离承诺发货时间还剩多久"显式暴露出来，并按剩余时间分级，
让运营按优先级处理，而不是按顺序处理。

## 二、术语定义

| 术语 | 含义 |
|---|---|
| 已过期 | 订单超过承诺发货时效且仍未发货 |
| 履约中 | 订单在承诺时效内，尚未发货 |

> 全文统一使用「已过期」，不要写成其他同义表述。

## 三、风险等级阈值

按剩余时间划分四档：

| 等级 | 剩余时间区间 |
|---|---|
| 紧急 | 0 ~ 2 小时 |
| 高 | 2 ~ 8 小时 |
| 中 | 8 ~ 12 小时 |
| 低 | 12 ~ 72 小时 |

超过 72 小时按已过期处理，进入单独的异常处理流程，不在本模块预警池内。

## 四、统计维度

仪表盘按以下 5 个维度下钻：

1. 时间
2. 客户
3. 商品分类
4. 支付方式
5. 渠道

## 五、列表字段

列表需展示的字段：

| 字段 | 说明 |
|---|---|
| 订单号 | 唯一标识 |
| 剩余时间 | 距承诺发货时间的剩余时长，精确到分钟 |
| 风险等级 | 按第三节阈值自动判定 |
| 商品类型 | 实物商品 / 虚拟商品 |

> 「剩余时间」与「风险等级」是两个正交字段：前者是客观时长，后者是按阈值派生出的标签，二者不可互相替代。
